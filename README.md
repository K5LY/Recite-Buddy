## 1. 产品概述

背背+（Recite-Buddy）是一款将**教材与考试大纲**转化为**分章精读背诵助手**的内容生成工具。使用者提供一本教材与对应考纲，产品自动产出手机优先、可离线使用、支持进度保存的单文件 HTML 页面，用于系统化备考精读与分章复习。

产品面向需要快速建立"考纲—章节—考点—记忆"复习闭环的用户，亦可供内容团队批量生成同系列复习材料。

## 2. 产品定位

| 维度 | 说明 |
|---|---|
| 产品形态 | 本地化 Skill 工具（Agent 调用） |
| 输入 | 教材 + 考试大纲 |
| 输出 | 单文件 HTML 背诵助手 |
| 使用场景 | 备考精读、教材导读、分章复习、应试背书 |
| 运行环境 | 手机 / 电脑浏览器，支持离线使用 |

## 3. 输入要求

| 材料 | 支持格式 | 说明 |
|---|---|---|
| 教材 | PDF / HTML / Word / 纯文本 | 需具备可识别的章节结构；无明确章节时按教材自身结构（导言/各章/结语）拆分 |
| 考试大纲 | PDF / 纯文本 | 用于考纲考点对齐与章节重要度判定 |

## 4. 核心功能

### 4.1 考纲考点对齐
每章先列出考纲考点，点击查看标准答案要点与答题结构模板。

### 4.2 考点动态分配
依据考纲掌握层级、分值占比、考查频次判定各章重要度：重点章考点数不设上限，非重点章可为 0；生成《考点分配表》供核对调整。

### 4.3 分章精读解析
逐段解析核心概念、关键术语与重点内容，含易错点与备考要点标注，每章末尾附知识总结表。

### 4.4 知识内链
正文中的人名、术语、展览可点击进入档案，支持嵌套跳转与逐级返回原阅读位置。

### 4.5 背诵闪卡
翻卡自测，「记住了 / 没记住」进度保存于本地（localStorage），刷新不丢失。

### 4.6 生僻字注音
注音仅服务于阅读与背诵：常用字不标注；外文名标注书中出现的外文原名（书中无原名则不标注，不自行补充）；中文专名仅标注不常见读音。

### 4.7 插图档案
教材自带图片放入对应档案，有图则放、无图不放。

### 4.8 主屏适配
支持 iPhone「添加到主屏幕」：汉字图标、全屏打开、无留白。

## 5. 使用说明

1. 提供教材与考试大纲文件。
2. 提出需求，例如："依据这份大纲，把这本书做成背诵助手 HTML"。
3. 产品自动执行完整流程：读取输入 → 章节拆分与考纲对齐 → 逐章精读 → 结构化数据 → 模板组装 → 主屏图标 → 验收交付。

## 6. 产出物

- 单文件 HTML（自包含，打开即用，无需联网依赖）
- 可访问链接（手机 / 电脑均可打开）
- 可选：主屏汉字图标

## 8. 常见问题

**Q：换一本新书能否复用？**
可以。数据、模板、脚本全部通用，新书只需重新提供"书 + 大纲"；每本书的背诵进度独立保存，互不干扰。

**Q：生成的页面需要联网吗？**
不需要。产物为单文件自包含 HTML。

**Q：注音标准是什么？**
以《通用规范汉字表》为基准：一级常用字不标注，二级慎收（仅学科必读且易读错），三级及表外（真生僻）标注；外文名仅标注书中出现的外文原名。
